通用规则与阅读约定

本说明覆盖个人中心、推广中心首页、团队、成员详情、回访、转移、收益明细及提现。页面内说明随当前操作切换；完整说明可独立查看。

点击、去向与返回

入口／区域触发结果与限制
原型说明点击展开／收起只改变说明面板，不切换业务页面；默认收起。
完整开发说明点击面板内链接在新标签页打开本文，可打印或另存为 PDF。
顶部小程序胶囊、状态栏无业务点击仅模拟设备环境，不触发关闭、菜单、网络或电量操作。
返回／取消／关闭优先关闭当前弹窗或返回来源页面普通页面使用页内返回；原型不写入浏览器路由历史，浏览器返回键不等同于页内返回。

字段与约束

字段规则
金额人民币；展示千位分隔，业务金额应按分存储、展示两位小数。现有收益明细示例允许 +¥30；订单授课费固定展示具体金额和 /小时，不展示范围。成员的「累计推广收益」指通过该成员相关业务，累计为当前推广人产生的推广佣金；不是成员报名或上课支付的总额，也不是成员本人的收入。
姓名与头像成员姓名：单字保留、双字首字加 *、三字及以上首尾保留中间为 *；头像使用姓名首字占位。注册／家长／老师列表和详情共用 40×40px 头像、16px 姓名字号；列表头像右置，详情头像左置。
手机号与隐私成员本人在列表、详情、回访弹窗完整显示并使用 tel: 拨打；订单交易对方、收益明细双方及转入来源提示使用前三位****后四位。转移搜索结果及转移记录中的手机号目前完整显示，正式权限策略见待确认。
时间详情、收益及转移记录保留完整年份和时分。列表回访／行动摘要仅显示 MM.DD HH:mm，完整时间保留在 title；新回访、转移使用浏览器本地时间。提现历史示例为 YYYY-MM-DD HH:mm，新记录为浏览器 zh-CN 本地格式，正式时间格式和时区需统一。
位置列表及详情头部为省·市·区；详情另有完整「所在位置」到小区／大厦。缺少行政区显示「未获取位置」，缺少详细位置显示「未获取详细位置」。现有详细地址全部为演示数据，未请求定位权限。
缺失与长文本不以 0 年教龄、空白科目或虚构地址替代缺失信息；用对应缺失提示。科目在列表最多取前三项，额外数量 +N，详情完整换行；回访摘要单行省略，完整内容在详情查看。
身份与权限主身份依次为老师＞家长＞仅注册。双身份只展示老师字段与老师标签，不显示家长标签／年级／意向科目／上课方式，不进入家长分类。转出与转入只影响跟进权限，不改变邀请归属。
只读与输入约束除明确列出的输入项外均为只读。学校、学历、科目、年级、地址等不是本页编辑表单，原型没有其录入长度校验；不能把显示样例当成完整业务枚举或接口必填规则。

联动、边界与验收

  • 原型为静态演示：回访、转移、余额、提现记录仅当前页面会话生效，刷新还原；银行卡另存于本地浏览器。没有真实注册、定位、审核、支付、短信、通知、微信 SDK 或跨账号数据同步。
  • 当前页面存在旧的一星／二星 DOM 与函数，但可见入口已移除。开发范围以本文列出的可达入口为准，不恢复星级团队、二星团队统计或成员分润页。
  • 手机画布外框及页面顶端背景为直角；内部卡片、按钮保留现有圆角。状态栏固定 44px，时间 15px，iPhone 图标 67×12px；小程序胶囊共用 87×32px 资源，不因内容增多压缩。
  • 收益和成员数据仅为演示快照；凡接口、结算、权限等尚未实现的内容在「正式接入待确认」列明，不宣称已实现。

个人中心

推广中心开通后在用户信息下方展示三个独立点击区域；其他个人中心服务为设计稿展示。

点击、去向与返回

入口／区域触发结果与限制
团队成员文案或人数点击进入「我的团队」；团队页返回回到个人中心。
累计收益文案或金额点击进入「我的账单」中的收益明细；返回回到个人中心。
进入推广中心点击进入「推广中心首页」；首页左上角返回个人中心。
未开通卡片的申请开通点击直接切换为已开通演示，不提交申请、不进入审批页面。
手机框外演示开通开关切换改变开通卡片展示；查询参数 creator=closed 首次进入未开通，其余值默认已开通，刷新按 URL 恢复。
其他图文服务入口点击仅设计稿展示，未绑定相应业务跳转；原型左上返回热点进入推广中心首页。

字段与约束

字段规则
用户头像／昵称／身份／会员提示示例唐小小、家长、会员未开通；首页保持同一设计和示例用户。不在本页编辑或申请会员。
团队成员当前个人中心 SVG 静态显示 87 人，与团队页实际演示总数 99 人不一致。正式口径以原团队总人数为准，含已转出成员、不含他人转入的 6 人且不随筛选改变；接入时三个入口应读取同一统计接口，不沿用静态 87。
累计收益演示 812,386.50 元；与首页及账单固定快照相同，不随分类、日期、转移或提现申请减少。

联动、边界与验收

  • 开通切换不清空本次会话的业务数据；仅作为演示控件，正式小程序不展示手机框外开关。

邀请好友海报与分享

海报标题为「邀请好友注册领榜家教」，品牌为「领榜家教」；专属二维码下方为白底分享面板。

点击、去向与返回

入口／区域触发结果与限制
微信点击尝试复制邀请链接，成功提示可在微信发送；权限失败则显示只读链接输入框并选中文本，供手动复制。当前不拉起微信 SDK。
保存图片点击下载 PNG，文件名「领榜家教邀请海报.png」；提示如未下载可长按海报保存。浏览器下载能力决定最终行为。
分享区下方居中关闭按钮／遮罩／Esc点击或按键关闭海报，回到原首页；关闭按钮在保存图片区域下方居中。

字段与约束

字段规则
海报750×850 像素 PNG；包含品牌、标题、二维码，不包含领取奖励、邀请人姓名或邀请说明。
二维码／复制链接两者使用同一 inviteUrl，模拟邀请码固定 LB10001；刷新及换站点时重新按当前地址生成，未连接邀请归因。
分享反馈复制失败有手动复制兜底；保存下载可能受浏览器限制，不以显示提示视为已完成真实微信分享或保存。

联动、边界与验收

  • 专属二维码原型可公开访问，但不写入真实好友关系、注册身份或团队人数。

我的团队 · 来源与筛选

成员来源切换位于页面内容顶部；仅团队成员页签显示团队概览，转跟进成员页签不显示团队成员总数和今日新增。身份和老师二级条件控制列表及结果数。

点击、去向与返回

入口／区域触发结果与限制
团队成员／转跟进成员切换来源顶部页签选择自己的 99 人或他人转入的 6 人；团队成员下显示团队总人数及今日新增，转跟进成员下隐藏整块统计。保留身份与老师筛选，退出批量并清空勾选，不额外展示来源说明提示。
身份：全部／注册／家长／老师单选立即更新列表与「共 X 位成员」；老师优先归类，家长列表不混入双身份老师。
老师类型／认证状态选择下拉项仅老师筛选下出现；两组单选并取交集。切走其他身份时隐藏并忽略，切回老师保留选项。
成员卡片／回访记录入口点击进入该成员详情，默认回访记录；电话、添加回访、转移跟进各自操作，不穿透整卡跳转。
注册卡片行动轨迹入口点击进入该成员详情并直接选中行动轨迹页签。
转移记录点击进入转移记录页；团队来源默认我转出的，转跟进来源默认我接收的；返回保持来源与筛选。
批量转移点击仅团队成员来源可用，存在可转移成员时启用，进入多选模式。
左上返回点击返回进入团队前的个人中心或推广中心首页。

字段与约束

字段规则
团队成员总数仅团队成员页签显示，当前完整原团队 99 人，包含已转出成员、不包含 6 位转入成员；不随身份筛选或批量选择改变。切换转跟进成员时隐藏，切回团队成员恢复同一总数。
今日新增仅团队成员页签显示，原团队注册日期等于浏览器今天的成员数；不是今日转入数、不随身份筛选变化。转跟进成员页签隐藏；正式统计以服务器业务时区为准。
主身份全部不分组；注册为尚未取得业务身份；家长为仅有家长身份；老师含双身份。原团队示例分别 12／38／49，共 99，互不重复。
老师类型枚举 all＝全部类型、professional＝专职老师、student＝大学生；类型来自显式字段，不用教龄或学历推断。
认证状态枚举 all＝全部状态、verified＝已认证、pending＝待审核；独立于老师类型。不按页面访问推断已认证。
共 X 位成员当前来源叠加主身份、老师二级条件后的成员条数，非全团队概览。页签只显示名称，不附人数。
空结果显示共 0 位成员及「暂无符合当前筛选条件的成员，请调整筛选项后查看」。不回退展示其他身份。

联动、边界与验收

  • 当前无成员姓名／电话搜索、分页或加载更多入口；列表一次展示全部筛选结果。正式分页方案另定，不能把批量全选默认为服务器全量。

三类成员列表卡片

共用头像右置、资料左对齐、浅底单行记录、底部集中操作的紧凑布局。

点击、去向与返回

入口／区域触发结果与限制
卡片空白区域点击进入当前成员详情；超出三项的科目 +N 不是独立弹窗，随卡片进入详情看全量。
成员电话及电话图标点击tel: 拨打该成员完整号码，不打开详情。
添加回访点击打开当前成员的添加回访弹窗；已转出不显示，转入可显示。
转移跟进点击打开当前成员转移弹窗；仅未转出的自有成员显示，转入不显示。
回访记录／行动轨迹点击进入该成员详情对应页签；回访默认 follow，行动仅注册卡片有入口。

字段与约束

字段规则
共用姓名／头像所有角色相同头像与姓名尺寸。成员姓名脱敏，不因身份不同缩小注册头像。
共用区域／手机号省·市·区及完整号码；文字过长按现有紧凑样式处理，详情完整展示地址。
家长身份／年级／科目顺序为姓名 [家长] 年级｜科目；不显示「意向科目」四字。科目前三项用顿号连接，多余项紧邻显示 +N；任一缺失显示未填写。
家长上课方式单独一行保留字段标题；当前成员资料 lessonMethod 为单值，枚举在线辅导／学员上门／教员上门，缺失未填写。收益记录 lessonMethods 为多值，不把两者混为同一接口结构。
老师类型／认证标签大学生或专职老师，附已认证或待审核；缺类型显示老师类型未填写。认证缺失目前不渲染状态标签，正式缺失文案待确认。双身份不带家长标签。
老师毕业院校＋学历／教龄同一行展示院校与学历、X年教龄；示例学历本科／硕士并非穷尽枚举。教龄为至少 1 的整数或空，空显示教龄未填写；院校、学历独立缺失提示。
老师辅导科目保留「辅导科目」标题；最多前三项＋N，详情完整显示；空显示未填写。
注册行动轨迹最新时间（不带年）＋行为名称＋行动轨迹入口；不显示行为说明全文或状态。无事件显示暂无行动轨迹，不显示伪造时间。
共用回访摘要时间（不带年）＋内容摘要＋回访记录入口压成一行；不显示最近跟进标签；无记录显示暂无跟进记录且无时间。
累计推广收益仅家长／老师显示，底部左侧，与回访／转移按钮分区。含义为通过该成员相关业务，累计为当前推广人产生的推广佣金，例如老师上课产生的分佣；不是报名支付总额或成员本人的收入。列表与详情共用同一 profit 演示值，展示人民币金额；转移和回访不改变。注册不显示，也不以 0.00 补位。
转入提示卡片顶部显示转出人脱敏姓名＋脱敏手机号＋转入时间；不支持再次转移。
转出提示卡片保留在团队，显示已转交接收人跟进；移除添加回访与转移按钮，历史可查看。

联动、边界与验收

  • 批量模式下整卡点击仅勾选／取消，卡片内部跳转和拨号不执行；已转出卡片不可勾选。

成员详情 · 用户资料与操作

基本资料、用户卡片下方操作、角色对应页签及记录列表；全页滚动，字段完整显示。

点击、去向与返回

入口／区域触发结果与限制
左上返回点击返回原成员列表，保留来源和筛选。
电话点击拨打当前成员本人完整手机号。
转移跟进／添加回访点击并排放在用户资料卡片下方、页签上方；同列表权限。转入只保留添加回访，已转出两者均隐藏，并显示交接提示。
回访／行动／需求／订单页签点击在同一详情内切换列表和 X 条标题，不换成员、不跳外页。每次重新打开成员默认回访，行动轨迹专属入口除外。

字段与约束

字段规则
共用资料头像、脱敏姓名、主身份标签、省·市·区、完整电话，以及独立所在位置字段；不展示星级、所属一星、二星入口。

家长资料与页签姓名后为家长标签，标签右侧为年级，不再单独列年级一行。下面为所在位置、意向科目（全部）、上课方式、累计推广收益。页签回访记录／需求记录／订单记录。
老师资料与页签类型＋认证标签；所在位置、教龄、毕业院校＋学历、辅导科目（全部）、累计推广收益。页签只有回访记录／订单记录；双身份完全按老师资料展示。
累计推广收益通过当前成员相关业务，累计为当前推广人产生的推广佣金，例如老师上课产生的分佣；不是报名支付总额或成员本人的收入。与列表卡片共用同一 profit 演示值，注册成员不显示；不随回访、转移或页签切换变化。是否包含待结算及退款冲销口径见正式接入待确认。
所在位置完整行政区＋小区／大厦，允许自然换行，不为压缩高度省略详细地址。三类均使用同一位置字段。
年级／科目／上课方式缺失显示未填写；年级为资料值，当前原型未定义全量年级枚举。上课方式沿用该家长资料单值。

高度压缩家长、老师减少资料行间距和留白，不删除其他字段；地址或多科目可换行，高度随内容增长，不固定裁切。
记录数量与空态按选中页签 records.length 展示 X 条回访记录／行动轨迹／需求记录／订单记录。无记录显示对应暂无记录和暂无可展示内容。
