# 领榜 · 个人中心小程序原型 2.0

以用户提供的个人中心SVG及后续确认的页面为基础，包含个人中心、会员中心、推广明细、邀请海报、历史抵用券和申请加盟。采用440 × 956逻辑画布、直角屏幕、实时iOS状态栏及微信胶囊。

本地预览：[个人中心](http://127.0.0.1:5198/)。每次打开或刷新均返回个人中心，其他页面通过界面内入口进入。手机外的创客开关可演示开通前后布局；会员状态可用 `member=active` 或 `member=expired` 预览。

```sh
npm run dev -- --host 127.0.0.1 --port 5198 --strictPort
npm run build
```

- 当前实现、字段、交互和验收：[原型开发与测试说明](docs/原型开发与测试说明.md)。
- 可追踪的需求编号及验收引用：[需求列表](docs/需求列表.md)。
- 原型画布外“原型说明”默认收起，展开后随页面、Tab、方案和弹窗联动；仅保留当前页面、需求列表两个页签；已确认规则归入对应业务说明。
- 说明数据统一维护在 `src/spec/prototype-spec.json`；`npm run docs:build`生成文档，`npm run docs:check`验证同源一致性。
- 编辑范围和运行时约定：[AGENTS.md](AGENTS.md)。
- 最近验证：[design-qa.md](design-qa.md)。
- 当前版本：2.0，记录于2026-11-22；完整源码、独立静态预览及校验清单保存在 `versions/2.0/`。
- 历史版本：`versions/1.0/`。1.0和2.0存档均不随后续开发更新。

本项目使用本地演示数据，不连接真实支付、发奖、微信发送、客服或申请提交。管理端配置不属于本项目。

当前规则：手机号唯一、首次有效邀请绑定；月度会员30天、年度365天，邀请1个月为30天；会员退款本期不做。已采纳方案与剩余联调项保留在完整开发文档的规则决策章节。`npm run test:business`核验固定天数、到期边界及手机号去重。
